# CH32V003-AMG88xx

This is an AMG88xx IR thermal camera library for
[CH32V003](https://www.wch-ic.com/products/CH32V003.html) RISC-V
microcontrollers.  It is based on [Adafruit AMG88xx
Library](https://github.com/adafruit/Adafruit_AMG88xx/) source code.  See
`README.Adafruit.md` file for details.

Examples of AMG88xx based boards:
- [Adafruit AMG8833 IR Thermal Camera Breakout - STEMMA
  QT](https://www.adafruit.com/product/3538)
- [Adafruit AMG8833 IR Thermal Camera
  FeatherWing](https://www.adafruit.com/product/3622)

## Requirements
- [ch32fun](https://github.com/cnlohr/ch32fun)
- [CH32V003_lib_i2c](https://github.com/mattybigback/CH32V003_lib_i2c/)
